# Third-party components

- The Gradle wrapper comes from FabricMC's official example project and the Gradle project (Apache-2.0). The wrapper downloads the verified Gradle distribution.
- Fabric API modules `fabric-api-base`, `fabric-lifecycle-events-v1`, and `fabric-key-mapping-api-v1` are included as nested JARs, retaining their upstream metadata and licenses (Apache-2.0).
- Fabric Loader/Mixin/MixinExtras and Minecraft are provided by the runtime and are not redistributed in this source archive.
- The 1,911 standard emoji PNGs, legacy compatibility textures and the custom-heart example use Apple artwork from `emoji-datasource-apple@16.0.0` plus eight Emoji 17.0 additions from emoji-data commit `13ee711e222ea17fe537bfea953c687866f16411` (https://github.com/iamcal/emoji-data). Apple artwork is copyright Apple Inc. and is excluded from this project's MIT license. The upstream project states that Apple images are not licensed for commercial usage. Source URLs and SHA-256 hashes are recorded in `emoji-asset-sources.json`. The data package license does not grant rights to Apple artwork.
- No Minecraft decompiled sources or game binaries are distributed in the source archive. No Chatting code/assets are included.


The emoji-data metadata uses the upstream MIT license included in EMOJI-DATA-LICENSE.txt. No skin-tone variant images are included.

- The CokeChat logo was supplied by the user for this project; it is included unchanged as assets/cokechat/icon.png.
